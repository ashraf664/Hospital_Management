# Hospital Management System

## وصف المشروع

مشروع لإدارة عمليات المستشفى من خلال تطبيق مكتبي تفاعلي، مع تنظيم الشيفرة بأسلوب البرمجة كائنية التوجه، وتنفيذ هياكل البيانات المطلوبة يدويًا، وحفظ البيانات في قاعدة بيانات محلية.

## التقنيات المستخدمة

- Python
- البرمجة كائنية التوجه (OOP)
- هياكل بيانات مخصصة تُنفّذ داخل المشروع
- CustomTkinter للواجهة الرسومية
- SQLite لقاعدة البيانات

## المميزات المخطط إضافتها

- إدارة بيانات المرضى والأطباء.
- تنظيم المواعيد والزيارات.
- حفظ السجلات الطبية.
- إدارة الأقسام والخدمات والفواتير.
- البحث عن البيانات وعرضها من خلال واجهة سهلة الاستخدام.
- تخزين البيانات محليًا والتحقق من صحة المدخلات.

> هذا المشروع في مرحلة إعداد الهيكل الأساسي فقط؛ لم تتم إضافة وظائف النظام بعد.
